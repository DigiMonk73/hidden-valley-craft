# Licences and outside assets

Every outside asset is listed here with its source and licence. Only free assets are used.

| What | Source | Licence | Used for |
|---|---|---|---|
| three.js 0.187.0 | npm `three` | MIT | rendering (bundled into the page) |

Everything else is original to this project:
- Block textures are drawn by code in `src/render/textures.ts`.
- The world is generated by code from `src/gen/layout.ts`.
- The game's icon (the falls with the tunnel's lamp behind them) is drawn by code in `tools/icon.ts`, which writes `assets/icon/`.
- The arm and what the hand holds, the birds, the rain and the glow round lamps are shapes built in code (`src/render/hand.ts`, `birds.ts`, `rain.ts`, `glow.ts`): no model or picture file.

There are no sound files: every sound is made in code at run time with the browser's Web Audio API.

Nothing here comes from Minecraft: no name, textures, sounds, creatures or interface art.
